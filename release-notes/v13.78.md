StreamForge v13.78 — Providers phone cards

- On phones (<=700px) the Providers page now renders real centered cards: every value has its label above it (PROVIDER, URLS, TOTAL, PRI, RUNNING, ALT, STATUS, ACTIONS), and the full URL shows on one line. Previously the table was squeezed into a scroll container whose URL column collapsed to ~63px, breaking URLs every 3-4 characters.
- Root cause: the providers table is not inside a `section.panel`, so the global responsive card pattern never matched it; v13.76's centering rules were no-ops on a table cell. The page now carries its own scoped card view.
- The v13.54-v13.77 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.78.zip
```
