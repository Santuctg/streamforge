# StreamForge v12.41

## Updater hotfix

- Fixed the v12.40 update failure: `v12.40 package contains stale/duplicate force updater scripts`.
- Root cause: the v12.40 bridge removed only `force_update_v1240.sh` from its staging copy, leaving both `force_update_v1236.sh` and the historical `force_update_v1239.sh`; the inherited full updater intentionally accepts exactly one version-specific force updater.
- v12.41 now removes every staged `force_update_v*.sh` except the inherited `force_update_v1236.sh` before running package integrity checks.
- Added a regression guard so future bridge releases cannot return to single-file staging cleanup.
- Includes the v12.40 Remote Node Access Panel cleanup and the v12.39 TLS/systemd CPU-loop fix.

## Update instructions

Download or rename the GitHub release source archive to `streamforge-12.41.zip`, then run:

```bash
streamforge-update --force /root/streamforge-12.41.zip
```

After Main update:

```bash
cat /opt/streamforge/VERSION
```

After Remote Node update:

```bash
cat /opt/streamforge-node/VERSION
/usr/local/sbin/streamforge-tls-fix-check
```

Expected version:

```text
12.41
```
