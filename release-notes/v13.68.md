StreamForge v13.68 — Providers count columns

- The Providers page now shows, per provider: **Total** (unique channels using the provider anywhere), **Pri channels** (primary input), **Pri running** (those live while streaming from the primary input), **Alt (backup) channels** (provider URL in their backup inputs) and **Alt running** (those actually running on this provider's backup URL right now — tracked through the encoder's active input index, so a failed-over channel is counted on the provider it is really streaming from).
- The v13.54-v13.67 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.68.zip
```
