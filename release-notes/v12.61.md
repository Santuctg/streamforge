# StreamForge v12.61 — Panel User Password Show/Hide

## Changes

- Adds a permission-gated **Change password** shortcut beside **Edit** on the desktop and mobile **Panel users** list.
- Opens the existing panel-user edit form and focuses the new-password input.
- Adds independently controlled **Show / Hide** buttons to **Password** and **Confirm password** fields. Both are hidden by default and become visible only when the operator clicks **Show**.
- Existing passwords **cannot be shown or recovered**: the database stores one-way scrypt hashes. The edit form never receives a plaintext password or hash.
- Leaving the Password field blank while editing preserves the existing password. Changing it still uses the existing server validation and authorization.
- No new password retrieval endpoint, no credentials displayed in listings, and no plaintext password logging/storage.
- Version metadata Main/Node Agent aligned at **12.61**; Node runtime payload unchanged from 12.60.
- Scoped installer backs up both panel-user templates and both VERSION files, validates Node runtime byte parity before writes, and rolls back on failure.
- Only `streamforge` and `streamforge-public` workers restart; neither channel supervisor nor Nginx is restarted.

## Deployment

On Main, download the official release ZIP and verify its published SHA256 before installation:

```bash
streamforge-update --force /root/streamforge-12.61.zip
```

Hard-refresh the Main panel. Open **Panel users → Change password** on a user. Enter a new password and confirmation, then click **Show** next to either input to reveal only what you typed. Click **Hide** to conceal it again. Save to apply the reset.

No separate Node ZIP is required.
