# StreamForge v12.85 — Node subscription expiry

## What changed

- **Node subscription expiry date.** Remote Nodes now have an `expires_at` field. When set and in the past, playback and channel access on that Node is blocked until the date is extended or cleared. Leave empty for unlimited (no expiry).
- **Expiry shortcuts in Node form.** The Add/Edit Node form gains a date-time picker with shortcut buttons: `+1 month`, `+2 months`, and `Unlimited (∞)`.
- **Migration script.** `scripts/migrate_node_expiry.py` adds the `expires_at` column to the `nodes` table. It is idempotent: safe to re-run.

## Upgrade

Requires installed Main **v12.84** or v12.85. Older servers must update in order.

Run the migration on the Main server:

```bash
python scripts/migrate_node_expiry.py
```

Then set expiry dates per Node from the Main Panel → Nodes → Edit Node.

Both VERSION files become 12.85. Remote Node runtime payload is unchanged — **Remote Nodes need no update for v12.85.**

## Verify

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.85`. Then open a Node edit page and confirm the "Node subscription expiry" field with `+1 month` / `+2 months` / `Unlimited (∞)` shortcuts.
