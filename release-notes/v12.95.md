# StreamForge v12.95 — Clearer Main dashboard Node counts

The Main dashboard Nodes card now presents:

- **Total Nodes** as the headline number (for example, `9`, not `9/9`).
- **Offline Nodes** beneath it.
- **Expired Nodes** after the offline count.

The expired count uses Bangladesh wall time. Node Agent behavior is unchanged; Remote Nodes do not need an update for this dashboard-only change.

## Upgrade

Requires installed Main **v12.94**. After updating, the Main dashboard Nodes card will display the three counts separately.

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.95`.
