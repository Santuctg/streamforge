# StreamForge v12.93 — Red expiry and centered payment notice

## What changed

- Expired subscription date/time now appears strongly red on both the Main Server Nodes page and the Node dashboard.
- The Node dashboard notice is centered and uses the requested text:

  **💰 Payment Pending**  
  The subscription has expired, so all channels are stopped until the payment is made. Once it is paid, everything resumes automatically.

- Expiry enforcement, Bangladesh-time interpretation, and backdated expiry editing are unchanged.
- New updater `scripts/force_update_v1293.sh`; both VERSION files bumped to 12.93.

## Upgrade

Requires installed Main **v12.92**. Update Remote Nodes from **Nodes → Node Updates** to apply the Node dashboard changes.

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.93`.
