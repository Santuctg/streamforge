StreamForge v13.18 — info-button help text on every panel

- Every inline help text in the Main panels now renders as a small ⓘ
  button next to its field caption (Username ⓘ, Max connections ⓘ,
  Enable user-based node load balancing ⓘ, ...).
- Hovering or focusing the button opens a white bubble with a downward
  pointer above it. Near the top edge the bubble flips below, it clamps
  to the viewport horizontally, and its arrow always points at the button.
- Clicking or tapping pins the bubble until you click it again, press
  outside it or press Escape; moving the pointer into the bubble keeps it
  open while you select or copy the text.
- The original help elements keep their identity, so dynamic texts (for
  example the Backup Destination path preview) keep updating while the
  bubble is open. Value badges such as "Effective now" and "Local ·
  Prefix pinned" stay inline and are not converted.
- Works across every template: plain grid labels, checkbox and radio
  cards, node source cards and sections that are revealed later.
- Main-only release: app/static/app.js and app/static/style.css carry the
  STREAMFORGE_HELP_TEXT_INFO_BUTTONS_V1318 marker, templates keep their
  markup and the conversion happens at runtime. Node Agent runtime bytes
  are unchanged and Remote Nodes need no update.

```bash
sudo streamforge-update --force /root/streamforge-13.18.zip
```
