# StreamForge v12.60 — Per-Node Inline Update Log

v12.60 keeps each Remote Node's running update log inside that Node's **Advanced** section on the dedicated **Node Updates** page.

## Changes

- Adds a **Live update log** panel inside every Node's expanded Advanced section.
- Reuses the existing per-Node background update-job logs already returned by `/nodes/{node_id}/update/status`; no new update engine or logging backend is introduced.
- Shows existing job log lines immediately when Advanced is opened and continues refreshing them from the existing 1-second status polling.
- Keeps each Node's log isolated from every other Node during parallel bulk updates.
- Auto-follows newly appended log lines when the viewer is already at the bottom of that Node's log.
- Preserves v12.59 toolbar/Advanced spacing, v12.58 unified update controls, and v12.57 parallel bulk-update behavior.
- Aligns Main and bundled Node Agent metadata at `12.60` while keeping the Node runtime payload byte-identical to v12.59.
- The Main updater changes only the Node Updates template and version metadata, restarts only `streamforge` and `streamforge-public`, and does not restart `streamforge-channel-supervisor` or reload/restart Nginx.
- No separate Node ZIP is required.

## Deployment

Update Main first:

```bash
streamforge-update --force /root/streamforge-12.60.zip
```

After installation, hard-refresh the panel, open **Node Updates**, then expand **Advanced** on a Node that is updating. Its own live update log should appear below the API/SSH controls and continue updating in real time.
