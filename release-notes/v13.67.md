StreamForge v13.67 — Providers page with per-provider channel counts

- New Providers page: add upstream providers with name, one or more URLs/hostnames, notes and an active flag.
- Per provider the list shows: how many channels use it as PRIMARY input, how many of those are RUNNING, and how many channels keep it as a BACKUP input — all separate.
- The provider edit page lists the matching channels in two columns (Primary / Backup) with each channel's running status.
- Channels match a provider by hostname of their primary input and every backup input (case-insensitive; port and path ignored), so one provider entry covers all its playlists/URLs.
- New permission group Providers (view/create/edit/delete) in the role editor; the sidebar shows the page for roles with View providers.
- The v13.54-v13.66 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.67.zip
```
