# StreamForge v12.55 — Final Main/Node version alignment

StreamForge v12.55 aligns the Main release and bundled Remote Node Agent on the same final version number without changing the proven Node runtime behavior from v12.52.

## What changed

- Main version is `12.55`.
- Bundled Remote Node Agent version is `12.55`.
- Adds `STREAMFORGE_VERSION_ALIGNMENT_V1255`.
- Verifies the bundled Node payload is byte-for-byte unchanged from the installed proven payload, excluding only `node_agent/VERSION`, before applying the alignment.
- Retains `STREAMFORGE_NODE_RELAY_HEALTH_PROBE_SINGLE_OWNER_V1251` and the v12.52 Node runtime behavior.
- Retains the v12.53 continuous Waiting timer and 60-second failed-input retry behavior.
- Retains the v12.54 atomic Main static-cache synchronization and SHA256 parity verification.
- Restarts only the Main HTTP workers during the Main update; it does not restart the Main channel supervisor or Nginx.
- Does not update Remote Nodes automatically.

## Update Main first

```bash
streamforge-update --force /root/streamforge-12.55.zip
```

After installation, verify:

```bash
cat /opt/streamforge/VERSION
cat /opt/streamforge/node_agent/VERSION
sha256sum /opt/streamforge/app/static/app.js /var/cache/streamforge/main-static/app.js
systemctl is-active streamforge streamforge-public streamforge-channel-supervisor
```

Expected versions:

- Main: `12.55`
- Bundled Node Agent: `12.55`

After the Main server is verified healthy, push the Node update to the Remote Node from the Main panel. There is no separate Node ZIP.
