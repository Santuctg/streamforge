StreamForge v13.08 — notification value and Node owner layout fixes

- Manual campaigns now receive each selected User/Node expiry date and calculated days remaining.
- Template replacement accepts `{expiry_date}`, `{{expiry_date}}` and whitespace variants.
- Node owner information is forced into one responsive, ellipsis-safe line.

Requires installed Main **v13.04** or newer.

```bash
sudo streamforge-update --force /root/streamforge-13.08.zip
```
