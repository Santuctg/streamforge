# StreamForge v12.71 — Main Login autofill and Blocked IP card layout

## Main Panel login — saved credentials in Chrome
Chrome and password managers can override the login Username/Password inputs with
a bright autofill background. Scoped CSS in `app/templates/login.html`
preserves the Main dark theme when credentials are saved, autofilled or
focused. Both inputs keep their normal autocomplete fields and the same
login/CSRF/session/password validation; **authentication is unchanged**.
New styles apply to Chrome/WebKit `-webkit-autofill` and the standard
`:autofill` selector, including autofilled focus, using an inset dark
box-shadow, light text fill, matching caret, border and dark color scheme.
No stored password is embedded in the HTML.

## Main Panel → Panel Users — independent IP security card
**Security · Panel Login · Blocked IPs** is now a separate top-level panel,
visually detached from **Login accounts** rather than nested inside its
border. The independent panel has:
- Clear section title, short operator-facing explanation, Refresh button
- Four compact policy facts: **5 incorrect logins**, **15 minutes**,
  **Automatic unblock after 3 hours**, **Main + Remote Nodes**
- Concise source-IP/NAT clarification and identification of which server
  triggered the fifth failure (older blocks may show Unknown)
- Count/status strip, scrollable six-column table, centered empty state
- Responsive two-column policy facts on smaller screens.

The Super Admin-only server/API/RBAC checks, existing manual unblock
password reauthentication, HTTPS same-origin and CSRF controls are
unchanged. This update does not alter IP blocking, login counting,
credential vault, Node runtime, stream delivery or channel scheduling.

## Deployment
From installed Main and bundled Node **v12.70**, install verified v12.71:
```bash
streamforge-update --force /root/streamforge-12.71.zip
```
The bounded updater changes **only**
`app/templates/login.html`, `app/templates/admin_users.html`
and Main/bundled Node VERSION metadata. It confirms unchanged Node
runtime byte hashes, runs layout and JS syntax regression tests,
backs up each file, handles re-install and restores on failure. It
restarts only Main HTTP services `streamforge` and `streamforge-public`;
running Remote Nodes, Nginx and supervisor are untouched.

After installation, reload the Main Login and Panel Users pages
(Ctrl+Shift+R if an old browser-rendered page remains).
