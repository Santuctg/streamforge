StreamForge v13.61 — Channels-page HLS preview gate

- Closed the last permission-audit gap found in the field: the Node Channels page rendered its HLS preview ("H") button without the `channels.playback` gate, so a role without "Open direct HTTP playback" still saw the button and only received a 403 on click. The button is now gated exactly like the dashboard one; the play routes already require `channels.playback`.
- Main's Channels, Dashboard and Channel Info pages were already server-gated by `can('channels.playback')`; the permission-audit contract now asserts every render site on both panels.
- If the H button still appears for an account after this update, that account is the Super-Admin (`permissions.all`) — roles cannot restrict it. Test with a user of the restricted role and hard-reload.
- The v13.54-v13.60 fixes are carried unchanged.

sudo streamforge-update --force /root/streamforge-13.61.zip
