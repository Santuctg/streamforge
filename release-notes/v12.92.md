# StreamForge v12.92 — Payment notice and backdated expiry edits

## What changed

- The Node dashboard now shows a clear, styled payment notice when the subscription expires: channels are off pending payment, and resume automatically after the Main Server extends the subscription. Added spacing so the notice is visually separated from the dashboard cards.
- Nodes → Edit now allows a past expiry date to be saved (removed the browser-side `min` restriction). This is useful for deliberate backdating; past values remain expired and the service lock stays active.
- The v12.91 Bangladesh-time semantics and v12.90 expiry enforcement are unchanged.
- New updater `scripts/force_update_v1292.sh` stages the Main node form and Node Agent; both VERSION files bumped to 12.92.

## Upgrade

Requires installed Main **v12.91**. Update Remote Nodes from **Nodes → Node Updates** for the new Node dashboard notice.

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.92`.
