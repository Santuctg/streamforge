StreamForge v13.56 — light dropdown selector match fix

- Fixed the light-theme dropdown option lists staying dark on Main and Node: every light select/option rule used the `:root[data-theme="light"] html body ...` selector, which can never match because `html` is not a descendant of `:root` — those rules had been dead since v13.48, so the native dropdown popup kept following the dark stylesheet's `color-scheme:dark`.
- The rules now use `:root[data-theme="light"] body select...` and carry the dark rule's `:not(#streamforge-dropdown-never)` id, so they also win the specificity fight (the dark rule's id would otherwise beat any light rule without it).
- Release guards now refuse any package whose light rules still use the impossible `:root[data-theme="light"] html` prefix or whose light select rules lost the id guard.
- The v13.54/v13.55 fixes are carried unchanged: the Main Web Player loads self-hosted HLS.js from the Nginx `/static/` cache, the Node watch route binds to the real player handler, and the Node panel/Web Player device Dark/Light theme works on every page.

```bash
sudo streamforge-update --force /root/streamforge-13.56.zip
```
