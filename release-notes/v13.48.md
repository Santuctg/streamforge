StreamForge v13.48 — complete light theme across the panels

- Fixed the remaining light-theme problems: page-level styles used to win over the light palette, so tables, cards, badges, dialogs, logs, notifications, Node Updates, backups, vault dialogs and settings forms stayed dark/unreadable.
- Added `app/static/theme-light.css`, loaded at the end of `<body>`, with every rule scoped to `data-theme="light"`. Dark mode is untouched.
- Main dashboard charts now draw theme-aware axes, grid lines, labels and tooltips and repaint immediately when the theme is toggled.
- Node panel hardcoded dark surfaces and near-white labels now have light equivalents.
- Main login screen now has the theme toggle too; Chrome autofill keeps the light field colour.
- Web Player: the light block now loads after saved appearance settings, and both the login-screen and header toggles work.

```bash
sudo streamforge-update --force /root/streamforge-13.48.zip
```
