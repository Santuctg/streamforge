# StreamForge v12.99 — Main Updates from the web panel

## Web update page

The sidebar now includes **Main Updates**. It displays the installed version, the latest official GitHub release, verification digest, job status, and an Update button.

## Security model

- Requires the new `main_system.update` permission (Super Admin has it automatically).
- The web process cannot run root commands or choose arbitrary URLs/files.
- A root-owned systemd helper independently re-fetches `Santuctg/streamforge` GitHub Releases metadata.
- It accepts only published, non-prerelease assets with the exact expected ZIP name and official GitHub URL.
- Every ZIP must have a GitHub SHA256 digest; download size, SHA256 and ZIP integrity are checked before installation.
- If the server missed multiple releases, verified pending releases are installed sequentially through the existing `streamforge-update` safety gates.
- Progress and final errors/results are displayed in the panel.

## First installation

Install v12.99 once using the normal ZIP command. After that, future official releases can be installed from **Main Updates**.

Requires installed Main **v12.98**. Remote Node Agent payload is unchanged.
