StreamForge v13.04 — Maestro SMS notifications

## What's new

- Notification Center now supports the Maestro SMS API (`sms.maestro.com.bd`) with encrypted API-key storage, sender ID, text/Unicode mode and a test SMS action.
- Stream Users and Node Server owners now have mobile-number fields and independent SMS notification toggles.
- Automatic SMS expiry reminders use the existing persistent delivery queue, retry policy and delivery history.

## Security and setup

- API keys are encrypted at rest and never rendered back to the browser.
- Configure SMS in **Notifications → SMS delivery settings**, then enable SMS and automatic SMS reminders only when desired.
- Rotate any API key that was accidentally exposed before saving the replacement in the Panel.

Requires installed Main **v13.03** or newer. Node Agent runtime bytes are unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.04.zip
```
