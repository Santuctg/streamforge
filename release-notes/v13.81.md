StreamForge v13.81 — collapsed sidebar scrolls

- In the collapsed desktop icon rail, the tall icon list could not be scrolled back to the top: an older Firefox fix made only #main-navigation a scroll container (`overflow:auto!important` + `flex:1 1 0!important`). The whole collapsed sidebar is now the scroll container, with the nav in normal flow, so every icon and the bottom actions are reachable.
- The v13.54-v13.80 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.81.zip
```
