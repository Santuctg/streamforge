StreamForge v13.72 — Panel pages always fresh

- Every Panel page render now answers with `Cache-Control: no-store, no-cache, must-revalidate`. After an update the browser always fetches the fresh page — a stale cached copy (which made the Providers Alt running column look uncentered after the v13.71 update) can no longer appear, and hard reloads are no longer needed for Panel pages.
- The v13.54-v13.71 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.72.zip
```
