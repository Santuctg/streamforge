# StreamForge v12.97 — All-clear Node dashboard statuses

- When there is at least one Node and none are offline, the Main dashboard shows **All nodes online**.
- When there is at least one Node and none are expired, it shows **All nodes active**.
- If any Nodes are offline or expired, their counts appear instead, aligned left/right. With zero Nodes, both status labels are hidden.
- Node Agent behavior is unchanged; Remote Nodes do not need an update.

Requires Main **v12.96**. After updating, verify with:

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.97`.
