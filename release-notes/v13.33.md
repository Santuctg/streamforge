StreamForge v13.33 — per-Node HLS segment override for shared channels

- Node operators can now change HLS segment duration for a Main-synced channel from the Node panel.
- The override is stored on Main for that specific Node + channel pair; other Nodes and the Main channel default are unchanged.
- `Keep current` prevents accidental bulk changes, while `Use Main default` clears the per-Node override.
- The affected Node channel is targeted and restarted so the new 1–20 second value applies immediately.

```bash
sudo streamforge-update --force /root/streamforge-13.33.zip
```
