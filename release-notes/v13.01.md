# StreamForge v13.01 — fully responsive Main Updates

## Responsive behavior

- Wide desktop: centered content with balanced three-column summaries
- Laptop/tablet: two-column cards with full-width status details
- Phone: compact single-column cards and full-width actions

Long request IDs, release names, SHA256 information, alerts and buttons now wrap safely without creating horizontal overflow. Update verification, privileged-helper isolation and installation behavior are unchanged.

Requires installed Main **v13.00**. Node Agent runtime bytes are unchanged, so Remote Nodes do not require an update.
