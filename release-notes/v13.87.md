StreamForge v13.87 — active link number in Channels

- The Channels table SERVERS column now shows the active input link number next to the local server name: "Main Server #1" for the primary input, "#2" (or higher) when a backup input is active. The number follows active_input_index, updates live when the source fails over, and survives bulk node re-assignment.
- The v13.54-v13.86 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.87.zip
```
