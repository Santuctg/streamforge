StreamForge v13.79 — topbar stays inside the screen

- On phones the topbar heading, subtitle and name chip no longer spill past the left and right screen edges. Root cause: an older mobile rule zeroed the bar's horizontal padding while main-content used 10px inline padding below 480px, so the -14px full-bleed margin pushed everything 4px outside both sides. The margin now matches the content padding at each breakpoint and horizontal padding is restored.
- The v13.54-v13.78 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.79.zip
```
