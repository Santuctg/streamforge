StreamForge v13.44 — device-local Dark/Light theme

- Added Dark/Light theme toggles to Main Server, Node Server, and Web Player.
- Each browser/device stores its own choice in `localStorage["streamforge.theme"]`; no server-side synchronization is used.
- Dark remains the default, and the selected theme survives reloads and future visits.

```bash
sudo streamforge-update --force /root/streamforge-13.44.zip
```
