StreamForge v13.06 — notification template and Node owner display fixes

- Fixed `{expiry_date}` and `{days_remaining}` rendering in email/SMS notifications.
- Both `{name}` and `{{name}}` variable syntax are accepted.
- Compacted Node owner name, email/mobile and expiry information into one responsive line in Notification Center.

Requires installed Main **v13.05** or newer. Node Agent runtime bytes are unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.06.zip
```
