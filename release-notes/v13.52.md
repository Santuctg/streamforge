StreamForge v13.52 — Main Web Player watch-screen Dark/Light theme

- Fixed the Main Web Player watch screen (`/123` → channel player) always defaulting to dark. `app/templates/player.html` now runs the same device-theme bootstrap as the home screen in `<head>`, so a saved light choice is applied before paint.
- Added the same Dark/Light toggle button to the watch-screen status row. The choice is stored in `localStorage["streamforge.theme"]` and follows the device/browser across reloads; dark stays the default.
- Added a scoped `html[data-theme="light"]` block that flips the watch screen's own dark gradients, panels, now-card, viewer info, channel tiles, category chips, status pills and inputs to a readable light palette. Dark theme computed colours are unchanged.
- Extended `scripts/verify_template_syntax.py` to render `player.html` in both the saved-appearance and default branches and assert the theme bootstrap, light block and toggle. The release workflow and the v13.52 updater refuse to install a watch screen that lost its theme.
- The v13.51 template hotfix, the v13.50 name-card switch and light-theme checkbox, and the v13.49 tokenised light palette are unchanged.
- Main-only change: Node Agent runtime bytes are unchanged and Remote Nodes do not need an update.
