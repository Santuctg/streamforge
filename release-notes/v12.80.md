# StreamForge v12.80 — Live Overview charts

## What changed

**The Overview charts now move on their own**, like the cards above them.

- **Every 5 seconds** the newest point of the CPU & Memory, Network Traffic and
  Online users charts follows the live values. It reuses the metrics refresh
  the cards already make, so it adds **no requests** to the server.
- **Once per history sample** (every 60 seconds by default, longer for long
  time spans) the full chart history is re-read quietly, so new samples, the
  Channels chart and the GPU charts advance without reloading the page.
- The quiet refresh **pauses** while the browser tab is in the background,
  while you are zoomed into a chart and while the pointer is over a chart, so
  tooltips and zoom are never disturbed. Double-click a chart to leave zoom
  and resume live updates.

Server cost: one small history request per sample interval per open Overview
tab, and nothing while the tab is hidden.

## Installation

Requires installed Main v12.79 (or v12.80 for a safe reinstall). Update older
servers in order (v12.78, then v12.79). Download and SHA256-check the
official release ZIP, then run:

```bash
streamforge-update --force /root/streamforge-12.80.zip
```

The updater patches staged copies of the installed `app/static/app.js` and
`app/static/dashboard.js` with `scripts/apply_v1280_live_charts.py`
(exact-text hunks; refuses if any anchor is missing), checks JavaScript
syntax, installs them atomically, **republishes them into the Nginx static
cache** (`/var/cache/streamforge/main-static`) and verifies that cache byte for
byte. Backups go to `/var/backups/streamforge/v1280-<timestamp>/`, including
the static cache; any failure rolls everything back. Only `streamforge` and
`streamforge-public` restart; Nginx, the channel supervisor and live streams
keep running. Reload the Overview page afterwards.

Remote Nodes need no update: the Node Agent is unchanged.
