# StreamForge v12.81 — Live Node Panel charts

## What changed

The Remote Node Panel dashboard gets the same chart improvements the Main
Overview received in v12.78–v12.80:

- **Current values beside the chart legends**: CPU and Memory usage, network
  Input and Output, Online users, Total and Online channels, and GPU usage,
  encoder, VRAM and temperature when a GPU is present.
- **"Loading…"** while the chart history is fetched, then "No history yet" or
  "Could not load history" if there is nothing to draw.
- **Live charts**: the newest point of CPU & Memory, Network Traffic and Online
  users follows the Node dashboard's existing 3-second refresh (**no extra
  requests**), and the full history is re-read quietly once per sample
  interval. Updates pause while the browser tab is in the background, while a
  chart is zoomed (double-click to reset) and while the pointer is over a
  chart.

The cards at the top of the Node dashboard already rendered with the page and
refreshed every 3 seconds, so they are unchanged.

## Installation

Requires installed Main/bundled Node v12.80 (or v12.81 for a safe reinstall).
Update older servers in order. Download and SHA256-check the official release
ZIP, then run:

```bash
streamforge-update --force /root/streamforge-12.81.zip
```

The updater replaces the **bundled** `node_agent/app.py` only after checking it
is the pinned v12.80 baseline, verifies every other Node runtime file
byte-for-byte, backs up to `/var/backups/streamforge/v1281-<timestamp>/` and
installs atomically. Backup, reinstall, baseline refusal and controlled
rollback are regression-tested. Only `streamforge` and `streamforge-public`
restart on Main; the channel supervisor, Nginx and live streams keep running.
No Main page changes in this release.

**Then update the Remote Nodes.** Open **Node Updates**, update every Node
(individually or in bulk) and confirm each reports v12.81. The Node update
reloads only the Node's HTTP workers; running relays keep playing. Reload a
Node Panel dashboard afterwards.
