# StreamForge v12.88 — Node expiry on Node pages only

## What changed

- **Removed node expiry from Main Panel dashboard (`/`)** — expiry date now shows only on Node pages (`/nodes/{id}`) as requested.
- Both VERSION files bumped to 12.88. Remote Node runtime payload unchanged — **Remote Nodes need no update for v12.88.**

## Upgrade

Requires installed Main **v12.87** or v12.88. Older servers must update in order.

## Verify

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.88`. Main Panel dashboard (`/`) no longer shows node expiry. Node pages (`/nodes/{id}`) still show Expires date.
