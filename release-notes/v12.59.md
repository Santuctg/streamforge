# StreamForge v12.59 — Node Update Center UI Spacing

v12.59 fixes the visual breakage reported on the dedicated **Node Updates** page without changing update behavior.

## Changes

- Groups `Select All`, selected-count, and `Update Selected` inside one intentional toolbar container.
- Adds consistent toolbar padding, border, radius, spacing, and responsive layout so the controls no longer look detached or broken.
- Adds visible vertical spacing between each Node row and the Advanced panel that opens beneath it.
- Preserves the v12.58 inline Advanced controls, live current-version refresh, and legacy redirect behavior.
- Preserves v12.57 bulk semantics: every selected Node starts immediately in parallel and one failure does not stop the others.
- Aligns Main and bundled Node Agent metadata at `12.59` while keeping the Node runtime payload byte-identical to v12.58.
- The Main updater changes only the Node Updates template and version metadata, restarts only `streamforge` and `streamforge-public`, and does not restart `streamforge-channel-supervisor` or reload/restart Nginx.
- No separate Node ZIP is required.

## Deployment

Update Main first:

```bash
streamforge-update --force /root/streamforge-12.59.zip
```

After installation, hard-refresh the panel and open **Node Updates**. The bulk toolbar should render as a single clean control bar, and an expanded Advanced panel should have visible spacing below its Node row.
