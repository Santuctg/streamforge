# StreamForge v12.98 — Retry Node channel starts after renewal

Fixed the case where channels did not auto-start after a Node subscription was extended:

- Keep pre-expiry desired-running intents persisted until the corresponding channel start is accepted.
- If a start fails temporarily, or the channel runtime is not loaded yet, retain its restore intent and retry on the Node expiry enforcement loop.
- Remove a restore entry only after a successful/accepted start. Existing lock behavior remains: expired subscriptions stop channels and block new starts.

Requires Main **v12.97**. Update Remote Nodes from **Nodes → Node Updates** so their Node Agent receives the fix.

Verify Main version with:

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.98`.
