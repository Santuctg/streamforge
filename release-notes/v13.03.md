StreamForge v13.03 — dark autofill fields for the Notification Center

## What's new

- **Autofilled inputs stay dark**: browsers used to paint autofilled fields — the Notification Center's *Test recipient*, SMTP username, *From email* and every other autofilled input in the Panel — with a light background that clashed with the dark theme. A global `:-webkit-autofill` override keeps autofill on the panel's dark field colors with readable text.
- **Static cache republish**: Nginx serves `/static/` from `/var/cache/streamforge/main-static`, so the updater now republishes that cache from the installed `app/static` tree and verifies it byte for byte before finishing. Browsers pick up the fixed stylesheet immediately via the `?v=13.03` cache buster.
- New bounded updater `scripts/force_update_v1303.sh`; both VERSION files bumped to 13.03. Node Agent runtime bytes are unchanged, so Remote Nodes do not require an update.

## Scope and safety

- No application logic, database, permission or Node Agent changes; the Notification Center and all v13.02 features are carried forward unchanged.
- The updater backs up the files it touches plus the static cache, rolls back automatically on failure, and never restarts Nginx or the channel supervisor.

Requires installed Main **v13.01** or newer (v13.01, v13.02). Node Agent runtime bytes are unchanged, so Remote Nodes do not require an update.

```bash
sudo streamforge-update --force /root/streamforge-13.03.zip
```
