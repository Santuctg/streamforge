- The Node Web Player expired screen now says:

  **Subscription Expired**  
  This subscription has expired. The Web Player is unavailable until payment is made. Once payment is received, access will resume automatically.

- The screen includes the Bangladesh expiry time followed by `· EXPIRED`, with the configured Node logo below the notice.

- Requires Main **v12.95**. Update Remote Nodes from **Nodes → Node Updates** to apply the Web Player changes.
