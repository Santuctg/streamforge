# StreamForge v12.72 — Redesigned Remote Node Panel login

The existing TS Live/other Remote Node Panel login was a compact 360px form
with plain inputs that browsers could autofill in bright colors. This release
replaces **only the Node login page presentation** with a consistent,
responsive dark design:

- Branded 440px card with subtle panel background and shadow
- Larger logo, descriptive login title, explicit Username/Password labels
- Accessible focus indicators, field spacing and full-width primary button
- Input colors and Chrome/WebKit autofill styling that respect dark theme
- Smaller-screen padding and reduced-motion support
- Existing logo fallback, HTML escaping, canonical browser address-bar script
  and role-specific login routes remain intact

**Security and functionality are unchanged:** Node auth continues to be
verified live against Main; five failed attempts from one IP in 15 minutes
still block new Panel logins from that IP for three hours. No new stored
passwords, password manager bypasses, weaker role checks, session changes,
or other streaming control changes were introduced.

## Installation

Requires bundled Main/Node source v12.70 or v12.71. Main v12.69 must first
be updated to v12.70, then the v12.72 release may be installed directly.
Download and SHA256-check the official release ZIP, then run:

```bash
streamforge-update --force /root/streamforge-12.72.zip
```

The scoped updater updates only the Main-server **bundled** Node Agent
`node_agent/app.py` and Main/Node version metadata, after pinned baseline
hash checking and byte-for-byte verification of every other Node runtime
file. Backup, safe reinstall and controlled rollback are regression-tested.
Main HTTP workers restart to pick up version metadata. Nginx, Channel
Supervisor and streaming processes are untouched.

**Running Remote Nodes are not upgraded automatically.** After installing
Main, use **Node Updates** to deploy the new Node Agent to TS Live and any
other Node. Verify the Node version displays v12.72. Refresh its login page
(Ctrl+Shift+R) to see the new dark login screen.
