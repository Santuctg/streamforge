StreamForge v13.62 — configurable password policy and forced password change

- Settings → Minimum password length: the operator picks 12 (recommended), 10, 8 or 6 characters. The minimum is enforced on Panel password changes, viewer (Xtream) passwords — which previously had no minimum — and every Remote Node panel; the Node password form renders the configured minimum client-side. Existing passwords stay valid until they are changed; the Panel keeps rejecting the installation default whatever the length.
- Force password change: the Admin Users page gains a per-user "Force password change" button (panel_users.edit) and a "Password change forced" badge. A forced user reaches only the password page at next login — on Main and on every Remote Node panel (Main mirrors the flag to Nodes in the panel-user sync and the live session auth). An operator-set password (Admin Users → Change password) is also marked temporary, so the user must replace it at next login; the user's own successful change clears the flag.
- The v13.54-v13.61 fixes are carried unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.62.zip
```
