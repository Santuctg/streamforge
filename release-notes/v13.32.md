StreamForge v13.32 — consistent full-width controls on phones

- On the phone layout (<=760px) the channel editor stacks every field in one column, but old desktop caps kept some controls shrunk: the "Primary-input check interval" input stayed 220px and the Categories picker stayed 260px while every other control filled the column, producing ragged half-empty rows. Below 760px all capped numeric inputs (program, failback, video/audio bitrate, fps, width, height, HLS segment) and the Categories picker now fill the stacked column like everything else. Desktop and tablet layouts are unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.32.zip
```
