# StreamForge v12.86 — Node expiry dashboard display

## What changed

- **Node expiry date shown on dashboard.** Nodes listing page (`/nodes`) now shows "Expires" on each node card. Past-due nodes get an "EXPIRED" badge in red; nodes without expiry show "Unlimited".
- **Update fix.** `force_update_v1285.sh` now stages updated templates from package source (`$SRC`) instead of installed root (`$ROOT`), so the expiry date field appears correctly in Node edit form after update.
- Both VERSION files bumped to 12.86. Remote Node runtime payload unchanged — **Remote Nodes need no update for v12.86.**

## Upgrade

Requires installed Main **v12.85** or v12.86. Older servers must update in order.

Run the migration on the Main server:

```bash
python scripts/migrate_node_expiry.py
```

Then set expiry dates per Node from the Main Panel → Nodes → Edit Node.

## Verify

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.86`. Then open `/nodes` and confirm each node card shows "Expires" with date or "Unlimited".
