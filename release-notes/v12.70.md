# StreamForge v12.70 — Exact 10-second saved-password reveal and cleaner Node form

## Main Panel — Panel Users → Show saved password

The Super Admin reauthentication field, explanatory line and **Reveal for 10
seconds** action now disappear **after successful verification**. Only the
account label and saved-password field with Show/Hide remain in the dialog.

The countdown is calculated from a single 10,000-millisecond monotonic
deadline (instead of a wrongly initialized 15-second counter). It shows
**Hides in 10 seconds** immediately, then 9 … 1. The secret is wiped
from the input and replaced by the reauthentication step at expiry,
on popup close, on page blur and when the document becomes hidden.
The password is never written to local storage, logs or HTML source.

Verification failures keep the Super Admin input visible so it can be retried.
Existing role-limited reveal, reauthentication throttle, CSRF,
HTTPS same-origin, no-store responses and audit logging are unchanged.

## Remote Node → Change password

The standalone line **New passwords are encrypted on Main and can be viewed by
authorized administrators.** is removed from below the form. The compact
account-managed credential disclosure now sits within the existing form
heading instead of adding a separate paragraph. This matters because updated
Nodes still securely retain new passwords on Main in administrator-recoverable
form; users must remain informed. The Node HTML form's labels, input layout,
authentication and managed-password signal remain unchanged.

## Deployment

The bounded updater accepts an installed Main and bundled Node version of
12.69 or 12.70. The release modifies only:
- `app/templates/admin_users.html` (Main reveal dialog JavaScript/CSS)
- `node_agent/app.py` (Node password page copy)
- Main and bundled Node VERSION metadata.

It pins the previously published Node source Git SHA, verifies unchanged
Node runtime files, performs functional reveal-timeline and syntax tests,
backs up each changed file, and rolls back on failure. Restart only the
Main `streamforge` and `streamforge-public` services; Nginx, supervisor
and already-running Remote Nodes remain untouched.

Install from the official verified v12.70 ZIP:

```bash
streamforge-update --force /root/streamforge-12.70.zip
```

After installing Main, use Main → **Node Updates** to deploy the v12.70
bundled Node to TS Live (and any other Node requiring the copy change).
Do not patch production source files manually because later releases
could overwrite them.
