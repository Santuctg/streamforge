# StreamForge v12.73 — Main backup restore, settings and admin account fixes

This release fixes three Main Server bugs:

- **Restore from a saved backup always failed.** Choosing a retained backup
  under Backups → Local files and confirming the restore ended with
  "Restore failed: name 'shutil' is not defined". Restores from saved
  archives now proceed normally; uploaded-archive restores were unaffected.
- **Branding/settings form returned a 500 on validation errors.** Saving
  with an empty brand name, or a rejected logo, favicon or YouTube cookies
  upload, crashed instead of showing the error message. The form now shows
  the error and keeps the page usable.
- **A deleted admin came back after every update or restart.** Main
  re-created `STREAMFORGE_ADMIN_USER` (with the `STREAMFORGE_ADMIN_PASSWORD`
  value from `/etc/streamforge.env`, default `ChangeMe123!`, as Super Admin)
  whenever that username was missing. It is now created only on a fresh
  install, when no Panel admin exists at all. If every admin is lost, recover
  with `scripts/reset_admin.py`.

No Node runtime, Nginx, Channel Supervisor, streaming, vault or login-guard
changes were introduced.

## Installation

Requires installed Main/bundled Node v12.72 (or v12.73 for a safe reinstall).
Update older servers to v12.72 first. Download and SHA256-check the official
release ZIP, then run:

```bash
streamforge-update --force /root/streamforge-12.73.zip
```

The scoped updater patches a staged copy of the installed `app/main.py` with
`scripts/apply_main_hotfixes.py` (each fix is skipped when already present,
so servers that applied the hotfix manually are fine), verifies the result,
then installs it atomically with Main/Node version metadata. Every other Node
runtime file is verified byte-for-byte unchanged. Backup, reinstall and
controlled rollback are regression-tested. Only the Main HTTP services
(`streamforge`, `streamforge-public`) restart.

Running Remote Nodes have no code changes in this release; updating them via
**Node Updates** only aligns their displayed version.

**Do not use `install.sh` to update an existing server**: it replaces the
installed, in-place-patched `app/main.py`.
