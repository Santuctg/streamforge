# StreamForge v12.90 — Expiry enforcement + Bangladesh 12-hour time

## What changed

- **Expiry now stops the service.** Once the Node subscription expires, the Node's control worker stops every running channel (paths persisted as stopped, FFmpeg killed) and refuses any new start. When Main extends or clears the expiry, the channels that were running before the lock resume automatically — no manual restart needed.
- **Bangladesh time, 12-hour clock.** The Node dashboard expiry card now shows BD time (UTC+6) like `02 Dec 2026 01:40 AM` (previously UTC 24-hour). While locked, a red banner explains that channels are stopped and renewal resumes them.
- Enforcement is wall-clock safe: a 30-second loop (env-tunable), immediate on heartbeat-synced expiry changes, and survives Node restarts (the pre-lock desired-state is persisted before stopping). Corrupt/invalid expiry values never lock the service. Public playback workers never enforce. The channel `start()` guard sits in front of the supervisor-delegation branch, so panel/API starts cannot bypass the lock.
- New updater `scripts/force_update_v1290.sh`; `scripts/update.sh` repointed to it. Also updates a local Node Agent at `/opt/streamforge-node` when present.
- Both VERSION files bumped to 12.90. Main Panel Server code is unchanged from v12.89 (it already sends `node_expires_at`).

## Remote Nodes

**Remote Nodes must be updated from Node Updates** to gain enforcement and the BD-time display. Until they are updated, they keep running v12.89 behaviour (expiry card in UTC, no enforced lock).

## Upgrade

Requires installed Main **v12.89**. Older servers must update in order.

## Verify

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.90`. Then:

1. Update the Remote Node(s) from **Node Updates**.
2. Open the Node dashboard and confirm the expiry card shows **BD 12-hour** time.
3. Test the lock: temporarily set an expiry in the past on Main (Nodes → Edit) — within ~30s every channel stops and the red banner appears. Extend the date — channels resume automatically.
