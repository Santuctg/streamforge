# StreamForge v12.45

## Relay log flood protection

- Stops expected relay `409` (restarting/waiting) and `410` (stopped) responses from filling `/var/log/nginx/access.log`.
- Continues logging other 4xx and all 5xx relay failures for diagnostics.
- Applies the policy to the fresh Nginx template and the Main runtime Nginx renderer.
- Installs `logrotate` automatically when missing and writes bounded Nginx rotation: daily, `maxsize 100M`, 7 rotations, compression.
- Carries forward the v12.44 dead-input schema-order updater protection and dashboard date/time changes.

## Update

```bash
streamforge-update --force /root/streamforge-12.45.zip
```
