StreamForge v13.21 — access-log actors and help-button layout

- Access-denied records no longer label policy-blocked unauthenticated requests as Guest; failed login attempts retain the submitted username, while passwords and tokens are never logged.
- A two-line help title such as “Primary-input check interval” now keeps its complete caption above the ⓘ button instead of placing the button over the second line or input border.
