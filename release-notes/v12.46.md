# StreamForge v12.46

## Updater relay-guard compatibility hotfix

- Fixes v12.45 update failure: `ERROR: v10.68 fresh relay access-log filter missing`.
- Rewrites the inherited v10.68 relay marker guards inside staging so they validate the v12.45 state-aware relay logging marker instead of rejecting it.
- Keeps relay `409`/`410` access-log suppression from v12.45.
- Keeps bounded Nginx log rotation and installs `logrotate` automatically when missing.
- Adds wrapper-owned `log`/`die` helpers so post-update logrotate setup cannot fail with `command not found`.
- Carries forward the dead-input schema-order migration protection and dashboard date/time changes.
