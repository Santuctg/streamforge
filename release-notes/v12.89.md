# StreamForge v12.89 — Node expiry on the Node's own dashboard

## What changed

- **"Subscription expires" card on the Node dashboard.** The Node's own panel (`/panel` — the page with CPU, Memory, Network Traffic charts) now shows the subscription expiry date: red with an `EXPIRED` marker past the date, green `Unlimited` when no expiry is set.
- Main sends `node_expires_at` in the Node heartbeat response (`STREAMFORGE_NODE_EXPIRY_HEARTBEAT_V1289`); the Node Agent persists it and renders the card. Edits on Main propagate to the Node within seconds.
- New updater `scripts/force_update_v1289.sh`; `scripts/update.sh` repointed to it. Also updates a local Node Agent at `/opt/streamforge-node` when present.
- Both VERSION files bumped to 12.89.

## Remote Nodes

The Node Agent payload changed for the first time since v12.83. **Remote Nodes must be updated from Node Updates** before their dashboards show the expiry card. Until then they keep running normally — this feature is display-only.

## Upgrade

Requires installed Main **v12.88**. Older servers must update in order.

## Verify

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.89`. Then:

1. Update the Remote Node(s) from **Node Updates**.
2. Open the Node's own dashboard (`/panel` on the Node) and confirm the **Subscription expires** card shows the date (or `Unlimited`).
3. Edit the expiry under **Nodes → Edit** and re-open the Node dashboard after a few seconds to confirm it follows.
