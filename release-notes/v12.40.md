# StreamForge v12.40

## Node Access Panel cleanup

- Removed the following controls from the **Remote Node server's own Access Panel / Settings page**:
  - Node Panel/API access URLs
  - Playlist/App access URLs
  - Panel access rules
  - Playback & catalog access rules
- Main Server Node Settings remain unchanged.
- Saving unrelated Remote Node settings now preserves the existing Main-synchronized Panel/API URLs, Playlist/App URLs, and IP/ASN access rules instead of clearing missing form fields.
- Added a Node Access Panel regression guard to ensure the four removed sections do not return and that the Main Server form remains intact.
- Retained the v12.39 persistent TLS request-file/systemd CPU-loop fix and its regression guard.

## Verification

Release checks cover:

- Python compile checks for Main and Node code.
- Node Access Panel cleanup regression guard.
- Node TLS reconciliation regression guard.
- Updater and shell syntax checks.
- Stale Remote Node settings form-read checks.
- Git diff whitespace validation.

## Update instructions

Download or rename the GitHub release source archive to `streamforge-12.40.zip`, then run on the Main server:

```bash
streamforge-update --force /root/streamforge-12.40.zip
```

On each Remote Node, update with the same v12.40 package using the installed StreamForge updater workflow.

After updating a Remote Node, verify:

```bash
cat /opt/streamforge-node/VERSION
/usr/local/sbin/streamforge-tls-fix-check
```

Expected version:

```text
12.40
```

The TLS verification should complete with no FAIL result.
