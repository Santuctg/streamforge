StreamForge v13.05 — separate SMS templates

- Added separate short SMS message templates for Stream Users and Node Server owners.
- Email subjects/bodies remain unchanged; SMS messages now use the configured SMS templates and support the existing notification variables.
- Maestro SMS text/Unicode delivery, encrypted API key storage, test SMS, phone fields and queued reminders remain available from v13.04.

Requires installed Main **v13.04** or newer. Node Agent runtime bytes are unchanged.

```bash
sudo streamforge-update --force /root/streamforge-13.05.zip
```
