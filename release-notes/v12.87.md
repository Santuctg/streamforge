# StreamForge v12.87 — Node expiry on Main Panel dashboard

## What changed

- **Node expiry date shown on Main Panel dashboard.** The dashboard page (`/`) now displays the count of nodes with expired subscriptions, with color-coded status (red = expired, green = all active).
- Both VERSION files bumped to 12.87. Remote Node runtime payload unchanged — **Remote Nodes need no update for v12.87.**

## Upgrade

Requires installed Main **v12.86** or v12.87. Older servers must update in order.

## Verify

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.87`. Then open `/` (Main Panel dashboard) and confirm the "Node expiry" stat card shows expired node count or "All active".
