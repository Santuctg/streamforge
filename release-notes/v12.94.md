# StreamForge v12.94 — Expired Web Player page and Main dashboard count

## What changed

- Once a Node subscription expires, the Node's Web Player root shows a dedicated **Subscription Expired** page instead of the player/login screen. It explains that payment and subscription renewal restore access automatically.
- The Main Server Overview dashboard now shows the number of expired Nodes in its Nodes card. The count uses Bangladesh wall time, matching expiry enforcement and the Nodes list.
- Existing expiry lock, auto-resume, Bangladesh-time display, and payment banner are unchanged.
- New updater `scripts/force_update_v1294.sh`; both VERSION files bumped to 12.94.

## Remote Nodes

Update Remote Nodes from **Nodes → Node Updates** to install the Web Player expiry page.

## Upgrade

Requires installed Main **v12.93**. Check with:

```bash
curl -fsS http://127.0.0.1:8800/version
```

Expect `12.94`.
