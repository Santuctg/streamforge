StreamForge v13.53 — Node Dark/Light audit fixes

- Audited every Node Agent surface for the device-local Dark/Light theme and fixed all findings.
- The Node panel's late light-theme overrides (hardcoded dark table rows, popovers, log pages, selects, chips) moved from the Categories-only stylesheet into the global `_node_panel_css()`, so every panel page now flips to light together, not just Categories.
- Fixed the Node panel light checkbox tick: a checked box keeps the teal fill and a dark centred tick (`#071c18`) instead of being painted near-white and looking empty — the same bug v13.50 fixed on Main.
- Added light overrides for Node panel surfaces that never had one: header logo/mark plates, logo previews, channel logo tiles and the video metric icon.
- The Node panel login page (`/panel/login`), the Main-disconnected page, the public Web Player login, home/channel list and watch screens, and the subscription-expired page now all run the shared device-theme bootstrap (`localStorage["streamforge.theme"]`, dark default) in `<head>`, show a Dark/Light toggle button, and carry scoped `html[data-theme="light"]` blocks. The choice persists per device/browser across reloads.
- Remote Nodes receive the updated Node Agent from Main automatically; local Node Agents are updated by the staged installer.
- The v13.53 updater refuses to install a package whose Node Agent lost the theme markers or whose templates do not compile.

```bash
sudo streamforge-update --force /root/streamforge-13.53.zip
```
