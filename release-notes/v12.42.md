# StreamForge v12.42

## Dead-input recovery control

- Added a configurable per-channel dead-input recovery interval.
- Default recovery interval is 30 minutes.
- Common values 5, 10, 15, 30, and 60 minutes are exposed in the channel form, with manual values from 1 to 1440 minutes supported.
- Normal source-to-source failover keeps the existing short retry backoff.
- After every configured input fails consecutively, StreamForge resets to primary input and waits the configured dead-input recovery interval before starting a new full input cycle.
- Primary failback probing remains controlled separately by `failback_interval`.
- Added an additive SQLite migration for existing installations; existing channels receive the 30-minute default automatically.
- Added regression checks for schema wiring, scheduler policy, recovery-cycle reset behavior, and Python syntax.
- Post-merge runtime simulation verified quick retry for early failures, configured long-delay scheduling after full-cycle exhaustion, reset to `active_input_index=0`, and successful recovery from the primary input.

## Update instructions

Download or rename the GitHub release source archive to `streamforge-12.42.zip`, then run:

```bash
streamforge-update --force /root/streamforge-12.42.zip
```

After Main update:

```bash
cat /opt/streamforge/VERSION
```

After Remote Node update:

```bash
cat /opt/streamforge-node/VERSION
/usr/local/sbin/streamforge-tls-fix-check
```

Expected version:

```text
12.42
```
