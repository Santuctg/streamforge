# StreamForge v12.44

## Adaptive historical graph date/time labels

- Main and Node dashboards now use the same adaptive historical graph date/time formatter.
- Up to 6 hours: X-axis shows time only, for example `02:35 PM`.
- More than 6 hours up to 48 hours: X-axis shows date and time on two lines, for example `09 Oct` and `02:35 PM`.
- More than 48 hours up to 31 days: X-axis shows `09 Oct`.
- More than 31 days: X-axis shows `09 Oct 2026`.
- Hover tooltips always show the complete local timestamp including date, year, time and seconds.
- Drag/click zoom automatically recalculates formatting from the visible time range, so zoomed history becomes more detailed without changing the selected source range.
- Applies to CPU & Memory, Network Traffic, Online users, Channels, GPU utilization and GPU temperature charts.
- Includes a Main/Node parity regression guard.
- Carries forward the v12.43 updater schema-order hotfix for `dead_input_recovery_interval`.

## Update

Download or rename the GitHub release source archive to `streamforge-12.44.zip`, then run:

```bash
streamforge-update --force /root/streamforge-12.44.zip
```

After updating Main:

```bash
cat /opt/streamforge/VERSION
```

Expected:

```text
12.44
```

After updating a Remote Node through the normal StreamForge Node update path, its Node dashboard receives the same adaptive date/time behavior and Node Agent version is `12.44`.
