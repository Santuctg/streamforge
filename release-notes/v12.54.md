# StreamForge v12.54 — Main static cache sync

This Main-only hotfix permanently fixes stale panel JavaScript/CSS after an update when Nginx serves `/static/` from `/var/cache/streamforge/main-static/`.

## What changed

- Adds `STREAMFORGE_MAIN_STATIC_CACHE_SYNC_V1254`.
- Syncs every packaged `app/static/` file into the installed Main static tree with atomic file replacement.
- Refreshes Nginx's direct static cache from the installed Main static tree after every v12.54 update.
- Verifies SHA256 parity for every packaged static asset in the package, installed tree, and Nginx cache.
- Backs up the previous installed static tree and Nginx static cache so updater rollback can restore both.
- Preserves unrelated cache-only files rather than destructively replacing the cache directory.
- Retains the v12.53 continuous Waiting timer and 60-second failed-input retry behavior.
- Keeps the bundled Remote Node Agent at v12.52; no Node push is required for this release.

## Update

```bash
streamforge-update --force /root/streamforge-12.54.zip
```

After installation, verify:

```bash
cat /opt/streamforge/VERSION
cat /opt/streamforge/node_agent/VERSION
sha256sum /opt/streamforge/app/static/app.js /var/cache/streamforge/main-static/app.js
```

Expected versions:

- Main: `12.54`
- Bundled Node Agent: `12.52`
