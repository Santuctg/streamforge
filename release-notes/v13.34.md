StreamForge v13.34 — fix shared HLS timeout and add Node channel sorting

- Fixed the Node-to-Main HLS override timeout: Main no longer calls back into the waiting Node request. The Node applies the confirmed effective value locally and restarts only the affected channel.
- Added Node channel list sorting: Main order, Name A–Z, Channel ID, Status, and HLS segment.
- Added a safe `Keep current` bulk option so mixed selections are not changed accidentally.

sudo streamforge-update --force /root/streamforge-13.34.zip
