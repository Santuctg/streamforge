Install a remote node

Use Auto install via SSH, or copy the v1.11.0 package and run the agent installer manually.

unzip streamforge_v1.11.0_channel_switch_geoip.zip
cd streamforge_mvp
sudo bash scripts/install_node_agent.sh --token YOUR_SECURE_TOKEN --port 80 --hostname panel-node1.example.com --dns-only --playlist-host stream-node1.example.com --public-port 80 --playlist-dns-only --panel-url https://panel.example.com --node-slug node-1

Then add http://node1.example.com:80 and the same token. DNS-only mode rejects ordinary requests made through the server IP.
